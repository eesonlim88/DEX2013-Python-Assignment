# Smart Machine Condition Monitoring and Safety Alert System

## Assignment
DEX2013 Programming for Engineering — Python Assignment

## Description
Reads the supplied machine dataset, classifies readings, calculates summary
statistics, and creates temperature and vibration graphs.

## Requirements
- Python 3
- pandas
- matplotlib
- os (for file path checking)

## How to run
1. Keep machine_condition_dataset.csv in the same folder as the Python file.
2. Install the required libraries if needed.
3. Run: python 1002681358_python_monitoring.py

## Output files
- temperature_vs_time.png
- vibration_vs_time.png

Note: This is a classroom simulation using example thresholds.
